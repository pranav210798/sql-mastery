# Chapter 32 — Real-World Projects

Four complete, professional-grade builds that apply the entire curriculum to
realistic systems. Each project uses one of the course's canonical databases,
lists functional/non-functional requirements, then implements them with full
SQL — schema extensions, procedures, functions, triggers, views, indexes, and
reports — with every result verified against the real seed data.

| # | Project | Database | Focus |
|---|---|---|---|
| 1 | [Employee Management System](01-employee-management.md) | `company_db` | Joins, hierarchy (recursive CTEs), procedures, HR workflow validation, reporting |
| 2 | [Banking System](02-banking-system.md) | `banking_db` | Transactions, row locking, deadlock-safe transfers, audit triggers, interest processing |
| 3 | [E-Commerce Database](03-ecommerce.md) | `ecommerce_db` | Concurrency-safe checkout, inventory locking, materialized views, index design |
| 4 | [Large-Scale Analytics Database](04-analytics.md) | `analytics_db` | Query optimization, partition pruning, window-function reporting at ~5M rows |

Work through them in order after finishing the corresponding chapters (see
each project's brief for its exact prerequisite range), or jump to whichever
matches the system you're building at work.
